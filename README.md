# 阅剧云 — 小说短剧一站式平台

## 📁 项目结构

```
yuejuyun/
├── index.html          # 主页面
├── css/
│   └── styles.css     # 样式表（现代简约风）
├── js/
│   ├── data.js        # 数据文件（小说+短剧）
│   └── app.js         # 应用逻辑
└── README.md
```

## 🚀 使用方式

直接用浏览器打开 `index.html` 即可，无需服务器。

如需本地服务器（推荐）：
```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`

## ✨ 功能

- 🔍 实时搜索（输入即过滤）
- 🏷️ 分类筛选（12个分类）
- 🏆 双榜排行（小说/短剧 TOP10）
- 📱 点击卡片查看详情弹窗
- 📊 数字递增动画
- 📱 响应式（手机/平板/桌面）
